# number-guessing-game-c
A simple Number Guessing Game in C where the user tries to guess a randomly generated number with hints and attempt tracking.

A fun and interactive **Number Guessing Game built in C**, where the computer generates a random number and the player must guess it with helpful hints.

---

## 📌 Features

- Random number generation
- User input validation
- Hint system (Too high / Too low)
- Attempt counter
- Simple and interactive gameplay

---

## 🧠 Concepts Used

- Random number generation (`rand()`)
- Loops & conditional statements
- Input/Output operations
- Basic game logic

---

## 🛠 Technologies Used

- Language: **C**
- Compiler: GCC / Turbo C
